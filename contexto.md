# CONTEXTO MAESTRO DEL PROYECTO: MORFA ESTUDIO

## 1. REGLAS DEL PROYECTO (Jóvenes creaTIvos - Ruta Básica)
- **Entregable:** Aplicación web full stack / funcional desplegada en GitHub Pages.
- **Módulos obligatorios:** 
  1. Landing / Inicio (marca, mensaje, secciones, navegación).
  2. Catálogo (productos/servicios con detalles claros).
  3. Contacto real (formulario funcional que registre o envíe solicitudes).
  4. Panel Admin (login y acceso a zona de gestión interna).
  5. IA aplicada (herramienta que aporte valor real al usuario o negocio).

## 2. IDENTIDAD Y NEGOCIO (CONFIRMADO)
- **Nombre:** MORFA Estudio (Logo: MORFA STUDIO).
- **Lema:** «Formando sueños».
- **Estética:** Minimalista, premium, geométrica, contemporánea. Colores base del logo: Crema cálido (#F5F2ED) y Negro carbón (#161616).
- **Actividad:** Modelado y visualización 3D combinado y adaptable (productos comerciales/renders para marcas y modelado técnico/industrial de piezas y objetos).
- **Propuesta de valor:** Transformar ideas, bocetos y conceptos en representaciones 3D claras y útiles antes de llevarlos a otras etapas.
- **Clientes objetivo:** Emprendedores y pequeñas marcas; diseñadores/creadores de productos; personas o pequeñas empresas con necesidades técnicas/industriales.
